### 5. 🏠 House Price Prediction

A **Machine Learning regression project** designed to predict house prices using property-related features.

### Dataset

* **Records:** 545
* **Features:** 13
* **Target:** House Price

The dataset included features such as area, bedrooms, bathrooms, stories, parking, air conditioning, furnishing status, and other property characteristics.

### Model

**Linear Regression — Scikit-learn**

### Evaluation

* **MAE:** 1,265,275.67
* **MSE:** 2,750,040,479,309.05
* **RMSE:** 1,658,324.60
* **R² Score:** 0.456

The reported R² score indicates that the model explained approximately **45.6% of the variance** represented by the target variable in the documented evaluation.

🔗 **Project Repository:** `[GitHub](https://github.com/kalashpriya/House-Price-Prediction-Machine-Learning-Project)`

### 6. 🧬 Breast Cancer Diagnosis

A **supervised Machine Learning classification project** using the Breast Cancer Wisconsin (Diagnostic) dataset.

### Dataset

* **Records:** 569
* **Columns:** 31
* **Features:** 30 computed features
* **Target:** Malignant / Benign

The project focused on classifying observations into malignant and benign categories.

### Model Performance

* **Accuracy:** 98.25%
* **Confusion Matrix:** `[[41, 1], [1, 71]]`
* **Malignant Precision:** 0.98
* **Malignant Recall:** 0.98
* **Malignant F1-Score:** 0.98
* **Benign Precision:** 0.99
* **Benign Recall:** 0.99
* **Benign F1-Score:** 0.99

The documented experiment reported strong classification performance with balanced precision and recall across both classes.

🔗 **Project Repository:** `https://github.com/kalashpriya/Breast-Cancer-Diagnosis-Machine-Learning-Project`
